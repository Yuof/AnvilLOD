# PenguLOD SKSE plugin

This plugin runs inside Skyrim. It provides dynamic LOD and the in-game quality controls for
output generated by PenguLOD. The generator is a separate download.

## Install

1. Install this ZIP with your mod manager.
2. In the installer, choose your Skyrim version:
   - SE 1.5.97 up to AE 1.6.1170
   - Newer than 1.6.1170
   - Skyrim VR 1.4.15
3. Enable the mod. It needs SKSE and Address Library for SKSE Plugins for your game
   version. On Skyrim VR these are SKSEVR and VR Address Library.

To install by hand, copy the `SKSE` folder from `common`, and the `SKSE` folder from the
folder named after your game version, into the game's Data folder.

Do not enable `AnvilLOD.dll` together with this plugin.

## Settings

`SKSE/Plugins/PenguLOD.ini` holds the plugin's settings. Changes saved from the in-game menu
are written to it.

Source code and documentation: <https://github.com/opteron-x86/PenguLOD>
